## Day 69 : Install Jenkins Plugins
1- Click on the "Jenkins" option from the Up navigation bar.

2- Login to Jenkins using username and password in task description.

3- Click on "Manage Jenkins"  > "Manage Plugins" > "Available Plugins" > Search for "Git plugin" and "Gitlab plugin" and install them.

4- After installation, click on "Restart Jenkins when installation is complete and no jobs are running" to restart the Jenkins server and apply the changes.
